- <Highlight>JavaScript</Highlight> is a dynamic scripting language used to make interactive web pages,
so it’s not designed for complex applications.

- <Highlight>TypeScript</Highlight>, on the other hand, is a static scripting language
that is a superset of JavaScript, meaning that it is an extra layer on top of your JS code.

- <Highlight>TypeScript</Highlight> was not designed to supersede or replace JavaScript. In fact, it never overrides existing behavior.
It takes the existing behaviors of <Highlight>JavaScript</Highlight> to correct its limitations and leverage common issues with the language.

There are many differences between <Highlight>TypeScript</Highlight> and <Highlight>JavaScript</Highlight>. Here are just a few:

- <Highlight>TypeScript</Highlight> is an object-oriented programming language whereas JavaScript is a scripting language (with support for object-oriented programming).

- <Highlight>TypeScript</Highlight> has static typing whereas JavaScript does not.

- <Highlight>TypeScript</Highlight> uses types and interfaces to describe how data is being used.

- <Highlight>TypeScript</Highlight> has interfaces which are a powerful way to define contracts within your code.

- <Highlight>TypeScript</Highlight> supports optional parameters for functions where JavaScript does not.
