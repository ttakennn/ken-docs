- <Highlight>TypeScript</Highlight> is a typed superset of JavaScript and was created by Microsoft in 2012 to aid JavaScript developers with large-scale applications.
<Highlight>TypeScript</Highlight>  was designed to help as a structuring mechanism for large codebases because it helps avoid common errors that would slow you down.
It makes it easier for teams to work on the same project, as the language allows for modification and produces readable code.
If there are multiple developers working on one project, <Highlight>TypeScript</Highlight>  can prevent a lot of wasted time on debugging.

- This language allows us to use our JavaScript skills more effectively. In fact, after you compile your code,
all the <Highlight>TypeScript</Highlight>  stuff goes away and produces clean, cross-platform safe JavaScript code. On top of being interoperable,
<Highlight>TypeScript</Highlight>  adds unique features, including static typing, interfaces, classes, and more.
