:::info
The <Highlight>groupBy</Highlight> operator in RxJS is used to group values from a source observable into multiple observables,
each corresponding to a specific key or criteria. It allows you to create separate streams for different subsets of the data
:::

Key features of the <Highlight>groupBy</Highlight> operator include:

- **Grouping by Criteria**: It groups values based on a specified key or criteria function, allowing you to categorize and process them separately.

```ts
  const numbers = from([1, 2, 3, 4, 5, 6, 7]);
  numbers.pipe(
    groupBy((x: number) => x % 2) // Grouping by even and odd numbers
  ).subscribe((groupObservable) => {
    groupObservable.pipe(
      toArray() // Convert each group into an array
    ).subscribe((groupArray) => console.log(groupArray));
  });

  // Output
  // [1, 3, 5, 7]
  // [2, 4, 6]
```

- The <Highlight>groupBy</Highlight> operator is applied to numbers, which groups the values based on whether they are even or odd.

- We subscribe to the resulting grouped observables, which are based on the criteria provided to <Highlight>groupBy</Highlight>.

- Inside the subscription to each grouped observable, we use the toArray operator to convert the values of each group into an array.

**Where Can We Use the <Highlight>groupBy</Highlight> Operator?**

The <Highlight>groupBy</Highlight> operator can be applied in various scenarios, such as:

- **Data Segmentation**: When you need to categorize and process data based on specific criteria,
such as grouping customers by age or products by category.
