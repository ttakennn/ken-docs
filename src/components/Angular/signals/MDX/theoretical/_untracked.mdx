Angular provided untracked function which allows you to execute any function in a non-reactive context and sometimes it will return values.

Please see the example as below:

```ts
export class AppComponent {
  count = signal(1);
  user = signal(0);
  nCount = untracked(this.count);
  factor = untracked(() => {
    const count = this.count();
    const users = this.users() || 5;

    return count / users;
  });

  revenue = computed(() => untracked(() => this.count() * 5));

  constructor() {
    // This effect method will be called only once since no signal property is used in its context.
    effect(() => {
      console.log('Empty effect method');
    });

    // The below effect will be called whenever the user signal is changed.
    effect(() => {
      console.log('User effect invoked ' + this.user());
    });

    // This callback will be invoked when either the user or count signal is changed.
    effect(() => {
      console.log('User and View effect invoked ' + this.user() + ' ' + this.count());
    });

    // This effect method will be called when the very first time the count signal is set then it will become inert since the count is wrapped in the untracked method. This method will help you execute the signals inside a non-reactive context.
    effect(() => {
      console.log('Count effect invoked ' + untracked(this.count));
    });
  }

  addCount() {
    this.count.update((val) => val + 1);
  }

  userChange() {
    this.user.update((val) => val + 1);
  }

  resetCount() {
    this.count.set(0);
  }
}
```

In the above code, <Highlight>nCount</Highlight> simply unwrap the signal value and <Highlight>factor</Highlight> will hold the result of the arbitrary function run inside the untracked function.

The <Highlight>revenue</Highlight> computed signal will be computed only once(value would be 5) based on its dependency count. For subsequent set operations, revenue will not recalculate and will remain in the same value.
