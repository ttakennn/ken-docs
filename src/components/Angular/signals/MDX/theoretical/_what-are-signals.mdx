:::info
:diamond_shape_with_a_dot_inside: A signal is a wrapper around a value that notifies interested consumers when that value changes. Signals can contain any value, from simple primitives to complex data structures.

:diamond_shape_with_a_dot_inside: You read a signal's value by calling its getter function, which allows Angular to track where the signal is used.

:diamond_shape_with_a_dot_inside: Signals may be either `writable` or `read-only`.
:::
