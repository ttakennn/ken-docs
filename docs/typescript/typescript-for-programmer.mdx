:::info
<Highlight>TypeScript</Highlight> began its life as an attempt to bring traditional object-oriented types to <Highlight>JavaScript</Highlight> so that the programmers at Microsoft
could bring traditional object-oriented programs to the web.

As it has developed,<Highlight>TypeScript’s</Highlight> type system has evolved to model code written by native <Highlight>JavaScripters</Highlight>.

The resulting system is powerful, interesting and messy.
:::
