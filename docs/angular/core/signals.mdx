### What are signals? :globe_with_meridians:

A signal is a wrapper around a value that notifies interested consumers when that value changes. Signals can contain any value, from simple primitives to complex data structures.

You read a signal's value by calling its getter function, which allows Angular to track where the signal is used.

Signals may be either `writable` or `read-only`.

### Writable signals

```js title="Create a signal"
  count: WritableSignal<number> = signal(0);
```

To change the value of a writable signal, use the `.set()`:

```js
count.set(3);
```

or use the `.update()` to add a new value from the previous one:

```js
count.update((value) => value + 1);
```

### Computed signals

```js
  count: WritableSignal<number> = signal(0);
  doubleCount: Signal<number> = computed(() => this.count() * 2); // read only
```

Computed signal are `read-only`. The `doubleCount` will not use `set()` or `update()`.

The `doubleCount` signal depends on the `count` signal. Whenever `count` updates, Angular knows that `doubleCount` needs to update as well.

### Effects

An `Effect` is an operation that runs whenever one or more signal values change.

`Effects` always run **at least once**.

`Effects` always execute **asynchronously**, during the change detection process.

```js
  @Component({...})
  export class EffectiveCounterComponent {
    readonly count = signal(0);
    constructor() {
      // Register a new effect.
      effect(() => {
        console.log(`The count is: ${this.count()})`);
      });
    }
  }
```

Alternatively, you can assign the effect to a field.

```js
  @Component({...})
  export class EffectiveCounterComponent {
    readonly count = signal(0);
    private loggingEffect = effect(() => {
      console.log(`The count is: ${this.count()})`);
    });
  }
```

To create an `Effect` outside of the constructor.

```js
  @Component({...})
  export class EffectiveCounterComponent {
    readonly count = signal(0);
    constructor(private injector: Injector) {}
    initializeLogging(): void {
      effect(() => {
        console.log(`The count is: ${this.count()})`);
      }, {injector: this.injector});
    }
  }
```

### Destroying effects

When you create an effect, **it is automatically destroyed when its enclosing context is destroyed**. This means that effects created within components are destroyed when the component is destroyed. The same goes for effects within directives, services, etc.

`Effects` return an `EffectRef` that you can use to destroy them manually, by calling the `.destroy()` method. You can combine this with the `manualCleanup` option to create an effect that lasts until it is manually destroyed. Be careful to actually clean up such effects when they're no longer required.

### Untracked

Angular provided untracked function which allows you to execute any function in a non-reactive context and sometimes it will return values.

Please see the example as below:

```ts
export class AppComponent {
  count = signal(1);
  user = signal(0);
  nCount = untracked(this.count);
  factor = untracked(() => {
    const count = this.count();
    const users = this.users() || 5;

    return count / users;
  });

  revenue = computed(() => untracked(() => this.count() * 5));

  constructor() {
    // This effect method will be called only once since no signal property is used in its context.
    effect(() => {
      console.log("Empty effect method");
    });

    // The below effect will be called whenever the user signal is changed.
    effect(() => {
      console.log("User effect invoked " + this.user());
    });

    // This callback will be invoked when either the user or count signal is changed.
    effect(() => {
      console.log(
        "User and View effect invoked " + this.user() + " " + this.count()
      );
    });

    // This effect method will be called when the very first time the count signal is set then it will become inert since the count is wrapped in the untracked method. This method will help you execute the signals inside a non-reactive context.
    effect(() => {
      console.log("Count effect invoked " + untracked(this.count));
    });
  }

  addCount() {
    this.count.update((val) => val + 1);
  }

  userChange() {
    this.user.update((val) => val + 1);
  }

  resetCount() {
    this.count.set(0);
  }
}
```

In the above code, <Highlight color="#4794c7">nCount</Highlight> simply unwrap the signal value and <Highlight color="#4794c7">factor</Highlight> will hold the result of the arbitrary function run inside the untracked function.

The <Highlight color="#4794c7">revenue</Highlight> computed signal will be computed only once(value would be 5) based on its dependency count. For subsequent set operations, revenue will not recalculate and will remain in the same value.
